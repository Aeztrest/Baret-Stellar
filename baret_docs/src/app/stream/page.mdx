# Stream Analysis

The streaming endpoint takes the same body as [batch](/batch) but sends each result as soon as it is ready, as Server-Sent Events. Transactions are analysed one after another, in order, so the first result arrives without waiting for the last. {{ className: 'lead' }}

---

## Stream transactions {{ tag: 'POST', label: '/v1/analyze/stream', id: 'stream-transactions' }}

<Row>
  <Col>

    ### Required attributes

    <Properties>
      <Property name="transactions" type="array">
        1 to 25 objects, each the same shape as the body of [`POST /v1/analyze`](/analyze).
      </Property>
    </Properties>

    The response is `Content-Type: text/event-stream`. The stream ends after the `complete` event. Send a `POST` body, so read the stream with `fetch` and a reader: the browser's `EventSource` cannot make POST requests. If a client disconnects, the server stops analysing the remaining items.

    The request is validated before the stream starts, so a bad body gets an ordinary `400 BAD_REQUEST` (or `401`, `429`) JSON error, not an event. Like a batch, a stream uses one request of your per-minute limit per transaction.

    <Note>
      `GET /v1/analyze/stream` still exists for older clients. It cannot carry a
      body, so it only answers with a `connected` event followed by an `error`
      event telling you to send a `POST`.
    </Note>

  </Col>
  <Col sticky>

    <CodeGroup tag="POST" label="/v1/analyze/stream">

    ```js {{ title: 'JavaScript' }}
    const res = await fetch('https://baret-stellar.onrender.com/v1/analyze/stream', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${process.env.BARET_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        transactions: [{ network: 'testnet', transactionXdr }],
      }),
    })

    const reader = res.body.pipeThrough(new TextDecoderStream()).getReader()
    let buffer = ''
    while (true) {
      const { done, value } = await reader.read()
      if (done) break
      buffer += value
      const messages = buffer.split('\n\n')
      buffer = messages.pop() // keep the incomplete tail
      for (const message of messages) {
        const event = /^event: (.+)$/m.exec(message)?.[1]
        const data = JSON.parse(/^data: (.+)$/m.exec(message)[1])
        console.log(event, data)
      }
    }
    ```

    ```python {{ title: 'Python' }}
    import json, os, requests

    with requests.post(
        'https://baret-stellar.onrender.com/v1/analyze/stream',
        headers={'Authorization': f"Bearer {os.environ['BARET_KEY']}"},
        json={'transactions': [{'network': 'testnet', 'transactionXdr': xdr}]},
        stream=True,
    ) as r:
        event = None
        for line in r.iter_lines(decode_unicode=True):
            if line.startswith('event: '):
                event = line[7:]
            elif line.startswith('data: '):
                print(event, json.loads(line[6:]))
    ```

## Event types {{ id: 'event-types' }}

<Properties>
  <Property name="start" type="event">
    First event. `{ "total": N }`: how many transactions will be analysed.
  </Property>
  <Property name="result" type="event">
    One per transaction, in input order: `{ "index", "status": "success", "decision" }` or `{ "index", "status": "error", "error": { "code", "message" } }`. `decision` is the same object `/v1/analyze` returns.
  </Property>
  <Property name="complete" type="event">
    Last event. `{ "total": N }`. The stream closes after it.
  </Property>
</Properties>

<CodeGroup>

```text {{ title: 'Example stream' }}
event: start
data: {"total":2}

event: result
data: {"index":0,"status":"success","decision":{"safe":true,"reasons":[],"riskFindings":[], …}}

event: result
data: {"index":1,"status":"error","error":{"code":"RPC_ERROR","message":"Stellar RPC is unavailable"}}

event: complete
data: {"total":2}
```

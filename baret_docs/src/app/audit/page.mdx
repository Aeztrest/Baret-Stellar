# Audit

The server keeps a short log of what it analysed. The audit endpoints read that log. {{ className: 'lead' }}

<Note>
  **Read this before you rely on it.** The log is held **in memory** (the last
  10,000 analyses) and is lost when the server restarts. It is **not separated by
  API key**: any valid key can read entries produced by every caller, including
  the `userWallet` and `integratorRequestId` values they sent. Treat it as
  operational telemetry for one server process, not a private per-customer history.
</Note>

---

## Recent records {{ tag: 'GET', label: '/v1/audit/recent', id: 'recent-records' }}

<Row>
  <Col>

    Returns the most recent analyses, newest first.

    ### Optional attributes

    <Properties>
      <Property name="limit" type="integer">
        How many entries to return. Default `50`, maximum `200`.
      </Property>
    </Properties>

    Each entry has `id`, `timestamp`, `network`, `safe`, `confidence`, `riskCodes` (the finding codes), `contractAddresses`, `primaryAction`, `userWallet` (or `null`), `integratorRequestId` and `durationMs`.

  </Col>
  <Col sticky>

    <CodeGroup tag="GET" label="/v1/audit/recent">

    ```bash {{ title: 'cURL' }}
    curl "https://baret-stellar.onrender.com/v1/audit/recent?limit=10" \
      -H "Authorization: Bearer $BARET_KEY"
    ```

    </CodeGroup>

    <CodeGroup>

    ```json {{ title: 'Response (abridged)' }}
    {
      "entries": [
        {
          "id": "0d6f3b3e-…",
          "timestamp": "2026-09-19T18:07:57.765Z",
          "network": "testnet",
          "safe": false,
          "confidence": "medium",

          "contractAddresses": [],

        }

    ```

    </CodeGroup>

  </Col>
</Row>

## Aggregate statistics {{ tag: 'GET', label: '/v1/audit/aggregate', id: 'aggregate-statistics' }}

<Row>
  <Col>

    Totals over the retained entries: how many were safe or blocked, the most common finding codes, and the contracts that appear most in blocked analyses.

    ### Optional attributes

    <Properties>
      <Property name="since" type="string">
        An ISO 8601 time. Only entries at or after it are counted.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup tag="GET" label="/v1/audit/aggregate">

    ```bash {{ title: 'cURL' }}
    curl "https://baret-stellar.onrender.com/v1/audit/aggregate?since=2026-09-19T00:00:00Z" \
      -H "Authorization: Bearer $BARET_KEY"
    ```

    </CodeGroup>

    <CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "totalAnalyses": 128,
      "safeCount": 101,
      "blockedCount": 27,
      "topRiskCodes": [

        { "code": "TRUSTLINE_CHANGE_DETECTED", "count": 11 }
      ],
      "topBlockedContracts": [
        { "contractAddress": "CBIELTK6…", "count": 8 }
      ],
      "timeRange": { "from": "2026-09-19T08:01:12.000Z", "to": "2026-09-19T18:07:57.765Z" }
    }
    ```

    </CodeGroup>

  </Col>
</Row>

## Contract audit {{ tag: 'GET', label: '/v1/audit/contract/:contractAddress', id: 'contract-audit' }}

<Row>
  <Col>

    Statistics for one Soroban contract address (`C…`): how often it appeared, how often those analyses were blocked, which finding codes came with it, and the latest entries.
    Contract addresses come from the transactions callers submit, so a contract that never existed on-chain can still appear here.

    ### Path and query parameters

    <Properties>
      <Property name="contractAddress" type="string">
        The contract address.
      </Property>
      <Property name="limit" type="integer">
        How many recent entries to include. Default `50`, maximum `200`.
      </Property>
    </Properties>

    `stats` is `null` when the contract has not been seen.

  </Col>
  <Col sticky>

    <CodeGroup tag="GET" label="/v1/audit/contract/:contractAddress">

    ```bash {{ title: 'cURL' }}
    curl https://baret-stellar.onrender.com/v1/audit/contract/CBIELTK6YBZJU5UP2WWQEUCYKLPU6AUNZ2BQ4WWFEIE3USCIHMXQDAMA \
      -H "Authorization: Bearer $BARET_KEY"
    ```

    </CodeGroup>

    <CodeGroup>

    ```json {{ title: 'Response (abridged)' }}
    {
      "contractAddress": "CBIELTK6…",
      "stats": {
        "contractAddress": "CBIELTK6…",
        "totalSeen": 42,
        "blockedCount": 8,
        "riskCodes": { "SOROBAN_ALLOWANCE_GRANTED": 8 },
        "lastSeen": "2026-09-19T18:07:57.765Z"
      },
      "recentEntries": []
    }
    ```

    </CodeGroup>

  </Col>
</Row>

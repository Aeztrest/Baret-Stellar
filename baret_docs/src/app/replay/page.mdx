# Replay

`POST /v1/replay` runs the raw simulation again and returns it, with no risk detectors and no policy. It is useful for debugging a simulation, or for re-checking a transaction after chain state changed. {{ className: 'lead' }}

<Note>
  **It is not historical.** Stellar cannot simulate a transaction against a past
  ledger, so replay always runs against **current** state. `isHistorical` is
  always `false`, and the optional `ledger` field is only echoed back as
  `replayLedger`. To get a verdict and findings, use [`POST /v1/analyze`](/analyze).
</Note>

## Replay a transaction {{ tag: 'POST', label: '/v1/replay', id: 'replay-a-transaction' }}

<Row>
  <Col>

    ### Required attributes

    <Properties>
      <Property name="network" type="string">
        `testnet` or `pubnet`. Must match the server's network, otherwise `400 WRONG_NETWORK`.
      </Property>
      <Property name="transactionXdr" type="string">
        Base64 `TransactionEnvelope` XDR.
      </Property>
    </Properties>

    ### Optional attributes

    <Properties>
      <Property name="ledger" type="integer">
        Informational only. Returned as `replayLedger`.
      </Property>
    </Properties>

    ### The response

    <Properties>
      <Property name="simulation" type="object">
        The normalized simulation: `status` (`success` or `failed`), `err`, `preflighted` (whether Soroban preflight ran; `false` for classic-only transactions), `accounts` (the pre-state of the accounts the transaction touches), `events`, `feeStroops`, `minResourceFeeStroops`, `authEntries` and `hostFnResultsXdr`.
      </Property>
      <Property name="replayLedger" type="integer | null">
        The `ledger` you sent, or `null`.
      </Property>
      <Property name="replayedAt" type="string">
        ISO 8601 time of the run.
      </Property>
      <Property name="isHistorical" type="boolean">
        Always `false`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup tag="POST" label="/v1/replay">

    ```bash {{ title: 'cURL' }}
    curl -X POST https://baret-stellar.onrender.com/v1/replay \
      -H "Authorization: Bearer $BARET_KEY" \
      -H "Content-Type: application/json" \
      -d '{ "network": "testnet", "transactionXdr": "AAAAAgAAAACd…" }'
    ```

    ```js {{ title: 'JavaScript' }}
    const { simulation } = await fetch('https://baret-stellar.onrender.com/v1/replay', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${process.env.BARET_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ network: 'testnet', transactionXdr }),
    }).then((r) => r.json())
    ```

    </CodeGroup>

    <CodeGroup>

    ```json {{ title: 'Response (abridged)' }}
    {
      "simulation": {
        "status": "success",
        "err": null,
        "preflighted": false,
        "…": "accounts, authEntries, events, fees"
      },
      "replayLedger": null,
      "replayedAt": "2026-09-19T18:08:01.120Z",
      "isHistorical": false
    }
    ```

    </CodeGroup>

  </Col>

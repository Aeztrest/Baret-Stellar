# Decode

`POST /v1/decode` reads a transaction and explains it: the operations in plain language, memo, time bounds, hash and the Soroban authorization tree. It makes **no network calls** and does **no risk assessment**, so it is fast. Use it to render a transaction, or to decide whether a full [analysis](/analyze) is worth running. {{ className: 'lead' }}

---

## Decode a transaction {{ tag: 'POST', label: '/v1/decode', id: 'decode-a-transaction' }}

<Row>
  <Col>

    ### Required attributes

    <Properties>
      <Property name="network" type="string">
        `testnet` or `pubnet`. Must match the server's network, otherwise `400 WRONG_NETWORK`.
      </Property>
      <Property name="transactionXdr" type="string">
        Base64 `TransactionEnvelope` XDR. An invalid envelope returns `400 BAD_REQUEST`.
      </Property>
    </Properties>

    ### The response

    <Properties>
      <Property name="hash" type="string">
        Hex hash of the (inner) transaction. This is the hash a verdict attestation binds to.
      </Property>
      <Property name="kind" type="string">
        `transaction` or `fee_bump`. For a fee-bump, a `feeBump` object carries the outer `hash`, `feeSource` and `fee`.
      </Property>
      <Property name="source, fee, sequence, memo, timeBounds, signatureCount" type="fields">
        Header fields of the (inner) transaction. `memo` is `{ type, value }`; `timeBounds` is `{ minTime, maxTime }` or `null`.
      </Property>
      <Property name="summary" type="object">
        `operations` (each with `index`, `type`, `action`, `description`, `details`), `humanReadable`, `primaryAction`, `involvedContracts`, `involvedAssets`.
      </Property>
      <Property name="cpiTrace" type="object">
        The Soroban authorization tree: `roots`, `allContractAddresses`, `maxDepth`, `totalInvocations`, `truncated`.
      </Property>
    </Properties>

  </Col>

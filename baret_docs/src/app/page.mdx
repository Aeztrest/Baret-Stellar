# Baret API

Baret reads a Stellar transaction before anyone signs it. You send the transaction envelope, Baret simulates it against current chain state, works out which balances move and what is risky about it, applies your policy, and returns a plain verdict: `safe` or not, with the reasons. {{ className: 'lead' }}

## How it works {{ anchor: false }}

Every call to `POST /v1/analyze` runs the same pipeline: decode the transaction (a fee-bump envelope is analysed through its inner transaction), read the accounts it touches from Horizon, run Soroban preflight when it contains a contract call, work out the estimated balance, trustline and allowance changes, run the risk detectors, then evaluate your `policy`. Nothing is signed or broadcast. {{ className: 'lead' }}

Two things to know before you integrate:

- **A server analyses one network.** The hosted demo server at `https://baret-stellar.onrender.com` is **testnet**. Ask `GET /v1/meta` which network a server runs; a request for the other one returns `WRONG_NETWORK`.
- **A finding only blocks when your policy says so.** Findings are always reported in `riskFindings`, but `safe` turns `false` only when the matching policy option is on (or the simulation failed, or the data was incomplete). See [Policy](/policies).
